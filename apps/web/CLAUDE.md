# apps/web

Next.js 16 / React 19 / Tailwind 4 frontend. Deployed as the Catalyst Slate app `web`.

Dev port: **4000** (`next dev -p 4000`).

## Reaching the API

Open the URL `catalyst serve` prints (first free port from 3000 up - often 3001), not
`:4000`. `apps/proxy` is the single origin: it forwards `/api/*` to the API on `:8000`
and everything else here. This app has **no rewrite or proxy config of its own**, so a
request made straight to `:4000/api/...` gets a Next.js 404, and one made to `:8000` is
cross-origin and missing the Catalyst headers the SDK needs.

Call the API with plain relative paths - `fetch("/api/...")` - and let the proxy route
it. That works identically in dev and in production.

Type responses with the shared shapes:

```ts
import type { RecordResponse, PagedRecordResponse, ErrorResponse } from "@repo/types/api";
```

`@repo/types` is not yet in this app's dependencies - add it as `"workspace:*"` the
first time you need it.

## Deployment

Slate builds this app from `.catalyst/slate-config.toml` (`pnpm install`,
`pnpm run build`, output `.next`). That file is generated and managed by the Catalyst
CLI - **do not hand-edit it**. Deployed from the repo root via `pnpm deploy`.
